# Traveling Salesman Problem Solver

This project implements a solution to the Traveling Salesman Problem using a brute-force approach.

## Installation

Run the following command to install the required packages:

```bash
pip install -r requirements.txt
```

## Usage

Run the main script:

```bash
python src/main.py
```

## Testing

To run the tests, use:

```bash
pytest tests/
```
